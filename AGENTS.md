# Repository conventions

- Write public documentation, repository descriptions, release titles, release notes, and commit subjects in English.
- Keep release notes concise and focused on changes that matter to users, with necessary setup or upgrade instructions.
- Keep test counts, build logs, lint results, signature checks, and implementation commentary out of release notes. Report validation in the development conversation or relevant technical review.
- Preserve the app's interface language unless a UI translation is requested.
- Keep the user's Git author identity. Add `Co-authored-by: Codex <codex@openai.com>` to commits created with Codex assistance.
- Attach only the installable APK to GitHub releases unless the user explicitly requests additional downloads. Keep logo files and other design assets in the repository.
